* Definition:  Metric space
:PROPERTIES:
:CUSTOM_ID: def:metric-space
:LECTURE_REF: 1.1.1
:END:

Given a set $X \neq \emptyset$, we say that a mapping $d_X : X \times X \rightarrow \left[ 0, \infty \right)$ is a metric if the following three properties are satisfied:

1. symmetry: for all $x, y \in X$,

   $$d_{X}(x, y) = d_X(y, x)$$

2. triangle inequality: for all $x, y, z \in X$,

   $d_X(x,z) \le d_X(x,y) + d_X(y,z)$

3. definiteness: for all $x, y \in X$.

   $$d_X(x, y) = 0 \iff x = y$$

If $d_X$ is a metric on $X$, then $(X, d_{X})$ is called a metric space.

* Definition:  Sequence
:PROPERTIES:
:CUSTOM_ID: def:sequence
:LECTURE_REF: 1.1.2
:END:

Let $X \neq \emptyset$ be an arbitrary set. A map $x : \mathbb{N} \rightarrow X$ is called a sequence in $X$ and we denote $x_n := x(n)$, for $n \in \mathbb{N}$. The sequence is also written as $(x_n)_{n\in\mathbb{N}} \subseteq X$.

* Definition:  Convergence
:PROPERTIES:
:CUSTOM_ID: def:convergence
:LECTURE_REF: 1.1.3
:END:

Let $(X, d_X)$ be a metric space. A sequence $(x_n)_{n\in\mathbb{N}} \subseteq X$ is said to converge to $x \in X$ if

$$\forall \epsilon > 0 \quad \exists N \in \mathbb{N} \quad \forall n \ge N \quad d_X(x_n, x) \le \epsilon$$

In this case, we write $\lim_{n \rightarrow \infty} x_n = x$ or simply $x_n \rightarrow x$ as $n \rightarrow \infty$.

* Theorem:     Uniqueness of limits
:PROPERTIES:
:CUSTOM_ID: thm:uniqueness-limits
:LECTURE_REF: 1.1.6
:END:

Let $(X, d_X)$ be a metric space. If $x_n \rightarrow x$ and $x_n \rightarrow x'$, then $x = x'$.

#+begin_proof
Assume $x \neq x'$. Then $\epsilon := d_X(x, x') / 3 > 0$. There exist $N_x, N_{x'} \in \mathbb{N}$ such that

\begin{align*}
d_X(x_n, x) &\le \epsilon \quad \forall n \ge N_x, \\
d_X(x_n, x') &\le \epsilon \quad \forall n \ge N_{x'}
\end{align*}

Hence, for $N = \max\{N_x, N_{x'}\}$, we have

$$d_X(x, x') \le d_X(x, x_N) + d_X(x_N, x') \le 2\epsilon = \frac{2}{3} d_X(x, x')$$

which is impossible unless $d_X(x, x') = 0$. This contradicts the assumption $x \neq x'$. $\square$
#+end_proof

* Definition:  Convergence order
:PROPERTIES:
:CUSTOM_ID: def:convergence-order
:LECTURE_REF: 1.1.7
:END:

Let $(X, d)$ be a metric space and suppose that $(x_k)_{k\in\mathbb{N}} \subseteq X$ converges to $x \in X$. Then we say that the convergence is

1. of order $r > 1$ if there is $c > 0$ and $k_0 \in \mathbb{N}$ such that

   $$d(x_{k+1}, x) \le c \, d(x_k, x)^r, \quad \forall k \ge k_0$$

2. linear if there is $c \in (0, 1)$ and $k_0 \in \mathbb{N}$ such that

   $$d(x_{k+1}, x) \le c \, d(x_k, x), \quad \forall k \ge k_0$$

3. sublinear if

   $$\limsup_{k \rightarrow \infty} (d(x_k, x))^{\frac{1}{k}} = 1$$

* Definition:  Isometry
:PROPERTIES:
:CUSTOM_ID: def:isometry
:LECTURE_REF: 1.1.10
:END:

Let $(X, d_X)$ and $(Y, d_Y)$ be metric spaces and $f : X \rightarrow Y$. Then $f$ is called an isometry if

$$d_Y(f(x), f(x')) = d_X(x, x'), \quad \forall x, x' \in X$$

* Definition:  Bounded sequence
:PROPERTIES:
:CUSTOM_ID: def:bounded-sequence
:LECTURE_REF: 1.1.11
:END:

Let $(X, d_X)$ be a metric space. A sequence $(x_n)_{n\in\mathbb{N}} \subseteq X$ is called bounded if there exists $x \in X$ and $C > 0$ such that

$$d_X(x_n, x) \le C, \quad \forall n \in \mathbb{N}$$

Analogously, we call a subset $S \subseteq X$ bounded if there exists $x \in X$ and $C > 0$ such that

$$d_X(s, x) \le C, \quad \forall s \in S$$

* Lemma:       Convergent sequences are bounded
:PROPERTIES:
:CUSTOM_ID: lem:convergent-bounded
:LECTURE_REF: 1.1.12
:END:

Let $(X, d)$ be a metric space. Every convergent sequence $(x_n)_{n\in\mathbb{N}} \subseteq X$ is bounded.

#+begin_proof
Assume $(x_n)_{n\in\mathbb{N}}$ converges to some $x \in X$. Then there exists $N \in \mathbb{N}$ such that

$$d(x_n, x) < 1 \quad \text{for all } n \ge N$$

Hence

$$d(x_n, x) \le \max\{d(x_1, x), \ldots, d(x_{N-1}, x), 1\} \quad \text{for all } n \in \mathbb{N}$$
#+end_proof

* Lemma:       Bounded monotone implies convergence
:PROPERTIES:
:CUSTOM_ID: lem:bounded-monotone-convergence
:LECTURE_REF: 1.1.15
:END:

If $(a_n)_{n\in\mathbb{N}} \subseteq \mathbb{R}$ is monotonically increasing and bounded from above, then it is convergent.

#+begin_proof
The order completeness of $\mathbb{R}$ ensures that $a := \sup_{n\in\mathbb{N}} a_n$ exists. Assume that $a_n \not\rightarrow a$. Then

$$\exists \varepsilon > 0 \quad \forall N \in \mathbb{N} \quad \exists n_N \ge N \quad |a_{n_N} - a| > \varepsilon.$$

The monotonicity implies that

$$a - a_N > a - a_{n_N} > \varepsilon \quad \forall N \in \mathbb{N},$$

and hence $a - \varepsilon > a_N$ for all $N \in \mathbb{N}$. This contradicts the property of the supremum to be the smallest upper bound.
#+end_proof

* Lemma:       Sequence in upper bounded set converging to supremum
:PROPERTIES:
:CUSTOM_ID: lem:sequence-converges-to-sup
:LECTURE_REF: 1.1.16
:END:

Let $S \subseteq \mathbb{R}$ be upper bounded. Then there exists a sequence $(x_n)_{n\in\mathbb{N}} \subseteq S$ such that

$$x_n \rightarrow \sup S.$$

#+begin_proof
The order completeness of $\mathbb{R}$ ensures that $s := \sup S \in \mathbb{R}$ exists. For all positive $n \in \mathbb{N}$, there is $x_n \in S$ such that

$$x_n \ge s - \frac{1}{n}.$$

Otherwise $s$ were not the smallest upper bound. We further deduce $\frac{1}{n} \ge s - x_n \ge 0$, which implies $x_n \rightarrow s$.
#+end_proof

* Theorem:     Convergence respects non-negativity
:PROPERTIES:
:CUSTOM_ID: thm:convergence-respects-non-negativity
:LECTURE_REF: 1.1.18
:END:

Suppose that $X = \mathbb{R}$ and $(a_n)_{n\in\mathbb{N}} \subseteq \mathbb{R}$ satisfies $a_n \rightarrow a$. Then

$$\forall n \in \mathbb{N} : a_n \ge 0 \quad \Rightarrow \quad a \ge 0.$$

#+begin_proof
Assume $a < 0$. Choose $\epsilon := -a/2 > 0$. Then there exists $N \in \mathbb{N}$ such that $|a_N - a| \le \epsilon = -a/2$. Hence

$$a_N - a = |a_N - a| \le -\frac{a}{2},$$

so $a_N \le a/2 < 0$. This contradicts $a_N \ge 0$.
#+end_proof

* Definition:  Cauchy sequence
:PROPERTIES:
:CUSTOM_ID: def:cauchy-sequence
:LECTURE_REF: 1.2.1
:END:

Let $(X, d_X)$ be a metric space. A sequence $(a_n)_{n\in\mathbb{N}} \subseteq X$ is called Cauchy sequence if

$$\forall \epsilon>0, \exists N \in \mathbb{N} : \forall n, m \ge N, d_X(a_n, a_m) \le \epsilon$$

** Questions

*** DONE How should I simply remember this definition in one sentence?

"A sequence is Cauchy if its terms eventually get arbitrarily close to each other."

- "eventually" = $\exists N$, from index $N$ onward
- "arbitrarily close" = $\forall \epsilon > 0$, distance $\le \epsilon$
- "to each other" = between any two terms $a_n$, $a_m$ (not to a fixed limit)

Pay attention to the last point. A convergent sequence's terms get close to a limit; a Cauchy sequence's terms get close to each other.

That distinction is the entire reason the concept exists — it lets you talk about convergence-like behavior without naming a limit, which matters when the limit might not live in your space ($\mathbb{Q}$ vs $\mathbb{R}$ being the canonical example).

* Lemma:       Rationals are not complete
:PROPERTIES:
:CUSTOM_ID: lem:rationals-not-complete
:LECTURE_REF: 1.2.6
:END:

The rational numbers $\mathbb{Q}$ are not complete.

#+begin_proof
Define a sequence $(x_n)_{n\in\mathbb{N}} \subseteq \mathbb{Q}$ inductively by $x_0 = 1$ and

$$x_{n+1} = \frac{1}{2}\left(x_n + \frac{2}{x_n}\right), \quad n \in \mathbb{N}.$$

A direct computation shows

$$x_{n+1} - \sqrt{2} = \frac{(x_n - \sqrt{2})^2}{2x_n} > 0.$$

Iterating this inequality yields

$$x_n - \sqrt{2} \le (x_{n-1} - \sqrt{2})^2 \le (x_{n-2} - \sqrt{2})^4 \le \cdots \le (x_0 - \sqrt{2})^{2^n}.$$

Another computation gives

$$\frac{x_{n+1}}{x_n} = \frac{1}{2}\left(1 + \frac{2}{x_n^2}\right) \le 1,$$

so the sequence is decreasing and bounded below by $\sqrt{2}$. In particular, $x_n \ge \sqrt{2}$ for all $n \ge 1$. Given $\epsilon > 0$, choose $N$ such that $(x_0 - \sqrt{2})^{2^N} < \epsilon$ (this is possible since $|x_0 - \sqrt{2}| < 1$). For $m \ge n \ge N$,

$$|x_m - x_n| = x_n - x_m < x_n - \sqrt{2} \le (x_0 - \sqrt{2})^{2^n} \le \epsilon.$$

Thus $(x_n)$ is a Cauchy sequence in $\mathbb{Q}$, but it converges to $\sqrt{2} \notin \mathbb{Q}$. Therefore, $\mathbb{Q}$ is not complete.
#+end_proof

* Theorem:     Real numbers are complete
:PROPERTIES:
:CUSTOM_ID: thm:reals-complete
:LECTURE_REF: 1.2.7
:END:

The real numbers $\mathbb{R}$ are complete.

We know by Theorem ?? that $\mathbb{R}$ is order-complete, meaning that every bounded set has an infimum and a supremum in $\mathbb{R}$. This is used to construct the limit for a Cauchy sequence.

#+begin_proof
Let $(x_n)_{n\in\mathbb{N}}$ be Cauchy. For $\varepsilon = 1$ there exists $N$ such that $|x_m - x_n| \le 1$ for all $m, n \ge N$. Hence for $n \ge N$,

$$|x_n| \le |x_n - x_N| + |x_N| \le 1 + |x_N|,$$

so $(x_n)_{n\in\mathbb{N}}$ is bounded.

For each $n$ set $A_n := \{x_k : n \le k\}$. Then $A_n$ is nonempty and bounded, hence

$$a_n := \inf A_n \in \mathbb{R}, \quad b_n := \sup A_n \in \mathbb{R}$$

exist by order completeness. We have $a_n \le x_k \le b_n$ for all $k \ge n$, $(a_n)_{n\in\mathbb{N}}$ is increasing, $(b_n)_{n\in\mathbb{N}}$ is decreasing, and $a_n \le b_n$.

Fix $\varepsilon > 0$ and choose $N$ such that $|x_m - x_k| < \varepsilon$ for all $m, k \ge N$. Then all elements of $A_N$ lie in an interval of length $\varepsilon$, hence $b_N - a_N \le \varepsilon$. Since $b_n$ decreases and $a_n$ increases,

$$0 \le b_n - a_n \le b_N - a_N \le \varepsilon \quad \forall n \ge N,$$

so $b_n - a_n \rightarrow 0$. This also implies

$$0 \le x_n - a_n \le b_n - a_n \rightarrow 0.$$

Define $a := \sup_{n\in\mathbb{N}} a_n$ and $b = \inf_{n\in\mathbb{N}} b_n$. Then we have $a \le b$ and $b_n - a_n \rightarrow 0$ yields $a = b =: \gamma$. Since $a_n \le \gamma \le b_n$, we deduce

$$0 \le \gamma - a_n \le b_n - a_n \rightarrow 0,$$

so that $a_n \rightarrow \gamma$. Finally, we have

$$|x_n - a| \le |x_n - a_n| + |a_n - a| \rightarrow 0.$$
#+end_proof

* Theorem:     Complex numbers are complete
:PROPERTIES:
:CUSTOM_ID: thm:complex-complete
:LECTURE_REF: 1.2.8
:END:

The complex numbers $\mathbb{C}$ are complete.

#+begin_proof
Given a Cauchy sequence $(z_n)_{n\in\mathbb{N}} \subseteq \mathbb{C}$, we may write $z_n = x_n + \mathrm{i} y_n$, where $x_n, y_n \in \mathbb{R}$. We directly compute

\begin{align*}
|z_n - z_m|^2 &= |x_n - x_m + \mathrm{i}(y_n - y_m)|^2 \\
&= |x_n - x_m|^2 + |y_n - y_m|^2.
\end{align*}

This implies that both $(x_n)_{n\in\mathbb{N}}$ and $(y_n)_{n\in\mathbb{N}}$ are Cauchy sequences in $\mathbb{R}$. Since $\mathbb{R}$ is complete, there are $x, y \in \mathbb{R}$ such that $x_n \rightarrow x$ and $y_n \rightarrow y$. We again obtain

$$|z_n - (x + \mathrm{i} y)|^2 = |x_n - x + \mathrm{i}(y_n - y)|^2 = |x_n - x|^2 + |y_n - y|^2.$$

Therefore, $|z_n - (x + \mathrm{i} y)| \rightarrow 0$.
#+end_proof

* Theorem:     Bolzano–Weierstraß
:PROPERTIES:
:CUSTOM_ID: thm:bolzano-weierstrass
:LECTURE_REF: 1.2.13
:END:

If $(a_n)_{n\in\mathbb{N}} \subseteq \mathbb{R}$ is bounded, then it contains a convergent subsequence.

#+begin_proof
Choose $A_0, B_0 \in \mathbb{R}$ such that $A_0 \le a_n \le B_0$ for all $n \in \mathbb{N}$. If we divide the interval $I_0 := \left[ A_0, B_0 \right]$ in the center, then either the right or the left half must contain infinitely many elements of the sequence $(a_n)_{n\in\mathbb{N}}$. We define $I_1$ to be the closed half that contains infinitely many elements.

Repeating this step with $I_1$ and so on leads to a nested family of closed intervals $(I_k)_{k\in\mathbb{N}}$,

$$I_k = \left[ A_k, B_k \right] \subseteq I_{k-1}, \quad B_k - A_k = 2^{-k}(B_0 - A_0),$$

such that each $I_k$ contains infinitely many terms of the sequence $(a_n)_{n\in\mathbb{N}}$.

Next, we construct a subsequence $(a_{n_k})_{k\in\mathbb{N}}$ such that $a_{n_k} \in I_k$ by induction. We start by $k = 0$ and choose $n_0$ with $a_{n_0} \in I_0$. Now we assume that we have found $a_{n_k} \in I_k$. Since $I_{k+1}$ contains infinitely many elements of the original sequence, there must exist $n_{k+1} > n_k$ with $a_{n_{k+1}} \in I_{k+1}$. Hence, we have constructed a subsequence $(a_{n_k})_{k\in\mathbb{N}}$ such that $a_{n_k} \in I_k$ for all $k \in \mathbb{N}$.

Given $\epsilon > 0$, choose $N$ with $2^{-N}(B_0 - A_0) \le \epsilon$. For $k, l \ge N$, both $a_{n_k}$ and $a_{n_l}$ lie in $I_N$, hence

$$|a_{n_k} - a_{n_l}| \le 2^{-N}(B_0 - A_0) \le \epsilon.$$

Thus $(a_{n_k})_{k\in\mathbb{N}}$ is Cauchy and therefore convergent because $\mathbb{R}$ is complete.
#+end_proof

* Definition:  Compactness
:PROPERTIES:
:CUSTOM_ID: def:compactness
:LECTURE_REF: 1.3.1
:END:

A metric space $X$ is called compact if every sequence $(x_n)_{n\in\mathbb{N}} \in X$ has a convergent subsequence $(x_{n_j})_{j \in \mathbb{N}}$ (with limit in $X$).

/Metric space $X$ is compact iff no matter how you pick an infinite sequence of points in $X$, you can always extract subsequence that converges to some point still inside $X$./

** Q&A

- Q_01

  About Sequence and Subsequence. Take for example the interval $(0,1)$, do we consider it as a sequence and then argue that its subsequence $\frac{1}{n}$ approaches $0$, which is outside the interval, making it not compact? Or it is just an interval and a subsequence that I gave, is actually a sequence that still proves its non compactness? Or maybe there is a third option of a sequence being its own subsequence?

- A_01

  The interval $(0, 1)$ is a set (the space), not a sequence. The sequence $\frac{1}{n}$ is a sequence in that set, and to disprove compactness you show that this sequence has no subsequence converging to a limit inside $(0, 1)$ — which is true because the whole sequence converges to $0$, forcing every subsequence to converge to $0$ as well, and $0 \notin (0, 1)$. Your second interpretation was essentially right: you exhibit a sequence in the space and show it defeats the compactness condition.

- Q_02

  Can a sequence in a compact space "escape" to a limit outside the space, while compactness only guarantees some subsequence stays inside?

- A_02

  No. Compactness actually prevents this entirely, for two reasons working together.

  First, a compact metric space is always closed, meaning if a sequence of points in $X$ converges at all, the limi tmust already belong to $X$ - there is nowhere to escape to.

  Second, if the full sequence converges to some limit $L$, then every subsequence converges to that same $L$, so there is no way for the sequence and a subsequence to "disagree" on where they end up.

  The only interesting case compactness handles is when the full sequence does not converge at all. Imagine a sequence that oscilates from $0$ to $1$, its subsequence, consisting only of $1$'s is convergent.

* Lemma:       Compactness implies completeness
:PROPERTIES:
:CUSTOM_ID: lem:compactness-completeness
:LECTURE_REF: 1.3.2
:END:

Every compact metric space is complete.

#+begin_proof
Let $(x_n)_{n\in\mathbb{N}} \in X$ be a Cauchy sequence. Since $X$ is compact, it has a convergent subsequence $x_j \rightarrow x \in X$ for $j \rightarrow \infty$. Given $\epsilon > 0$, there are $N_1, N_2 \in \mathbb{N}$ such that

\begin{align*}
d_X(x_n, x_m) &\le \frac{\epsilon}{2}, & \forall n, m &\ge N_1 \\
d_X(x_{n_j}, x) &\le \frac{\epsilon}{2}, & \forall j &\ge N_2 \\
\end{align*}

Let $N := max(N_1, N_2)$. Then for all $n \ge N$ we have $n_N \ge N_1$ and

$$d_X(x_n,x) \le d_X(x_n, x_{n_N}) + d_X(x_{n_N}, x) \le \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon$$

Thus, $x_n \rightarrow x$.
#+end_proof

* Definition:  Open and closed subsets
:PROPERTIES:
:CUSTOM_ID: def:open-closed-subsets
:LECTURE_REF: 1.3.3
:END:

Let $X$ be a metric space and $x \in X$.

1. We define a ball $B_{\epsilon}(x)$ of radius $\epsilon \ge 0$ and its interior $\mathring{B}_{\epsilon}(x)$ by

   \begin{align*}
   B_{\epsilon}(x) := \left\{ y \in X : d_X(x, y) \le \epsilon \right\} \\
   \mathring{B}_{\epsilon}(x) := \left\{ y \in X : d_X(x, y) < \epsilon \right\} \\
   \end{align*}

2. We say a set $S \subseteq X$ is open if

   $$\forall x \in S \quad \exists \epsilon > 0 : B_{\epsilon}(x) \subseteq S$$

3. We say that $S \subseteq X$ is closed if its complement $X \setminus S$ is open

4. We call $S \subseteq X$ a neighborhood of $x$ if there is $\epsilon > 0$ such that $B_{\epsilon}(x) \subseteq S$

** Q&A

- Q_01

  But why does the open set definition uses closed ball and not an open ball?

- A_01

  The two formulations define exactly the same concept of openness because fitting a closed ball of radius $\epsilon$ inside a set implies you can fit an open ball of the same radius (it's smaller), and fitting an open ball of radius $\epsilon$ implies you can fit a closed ball of radius $\frac{\epsilon}{2}$ inside it. Your lecturer chose the closed ball version, but it's purely a matter of convention — the resulting notion of "open set" is identical either way.

* Lemma:       Sequential closure
:PROPERTIES:
:CUSTOM_ID: lem:sequential-closure
:LECTURE_REF: 1.3.6
:END:

Let $X$ be a metric space and $S \subseteq X$ a nonempty subset. Then $S$ is closed iff all sequences $(x_n)_{n\in\mathbb{N}} \subseteq S$ with $x_n \rightarrow x \in X$ satisfy $x \in S$.

/In other words, $S$ is closed iff it contains all limits of its converging sequences./

#+begin_proof
- ($\Rightarrow$) Let $S$ be closed. Proof by contradiction, so assume that $(x_n)_{n\in\mathbb{N}} \subseteq S$ and $x_n \rightarrow x \in X \setminus S$. Since $X \setminus S$ is open, there is $\epsilon > 0$ such that $B_{\epsilon}(x) \subseteq X \setminus S$. By convergence, there is $N \in \mathbb{N}$ such that

  $$d_{X}(x_n, x) < \epsilon \quad \forall n \ge N$$

  In particular, $x_N \in B_{\epsilon}(x) \subseteq X \setminus S$, which contradicts $(x_n)_{n \in \mathbb{N}} \subseteq S$.

  /so basically, we are using convergence to find a $x_N \in B_{\epsilon}(x) \subseteq X \setminus S$, which will contradict the assumption that $(x_n)_{n\in\mathbb{N}} \subseteq S$/

- ($\Leftarrow$) We prove the contrapositive. Suppose $S$ is not closed. Then $X \setminus S$ is not open, so there exists $x \in X \setminus S$ such that for all $\epsilon > 0$, the ball $B_{\epsilon}(x)$ is not contained in $X \setminus S$. That is, for every $\epsilon > 0$, there exists a point in $B_{\epsilon}(x) \cap S$. Choosing $\epsilon = \frac{1}{n}$ for each $n \ge 1$ yields a point $y_n \in B_{1/n}(x) \cap S$. By construction, $d_{X}(y_n, x) < \frac{1}{n}$ for all $n \ge 1$, so $y_n \rightarrow x$. Since each $y_n \in S$ but $x \in X \setminus S$, we have found a sequence in $S$ converging to a limit outside $S$.

  /here we are proving by contrapositive, choosing some point $x \in X \setminus S : \forall \epsilon > 0, B_{\epsilon}(x) \not\subseteq X \setminus S$ (equivalently, $B_{\epsilon}(x) \cap S \neq \emptyset$), then taking balls of radius $1/n$ gives a sequence that is inside of $S$ that converges to $x \in X \setminus S$, hence it is not sequentially closed./


** Q&A

- Q_01

  But isn't it the same as compactness?

- A_01

  Closedness says "limits that exist stay inside," while compactness says "convergent subsequences are guaranteed to exist and their limits stay inside." Closedness is the weaker condition — it doesn't prevent sequences from diverging to infinity, it only controls where limits land when convergence does occur. Compactness implies closedness, but not the other way around; you additionally need boundedness (in $\mathbb{R}^{n}$) to upgrade closedness to compactness.
#+end_proof

* Lemma:       Compactness implies boundedness and closure
:PROPERTIES:
:CUSTOM_ID: lem:compactness-bounded-closed
:LECTURE_REF: 1.3.7
:END:

Let $X$ be a metric space. If $S \subseteq X$ is compact, then $S$ is bounded and closed.

#+begin_proof
Assume that $S$ is unbounded. Fix $x_0 \in X$. Then for every $n \in \mathbb{N}$ there exists $x_n \in S$ such that

$$d(x_n, x_0) \ge n.$$

Thus we obtain a sequence $(x_n)_{n\in\mathbb{N}} \subseteq S$.

Due to compactness, there exists a subsequence $(x_{n_k})_{k\in\mathbb{N}}$ that converges to some $x \in S$.

Every convergent sequence in a metric space is bounded by [[#lem:convergent-bounded][Lemma 10.1.11]], hence there exists $M > 0$ such that

$$d(x_{n_k}, x_0) \le M \quad \forall k \in \mathbb{N}.$$

On the other hand, by construction,

$$d(x_{n_k}, x_0) \ge n_k \ge k,$$

which is unbounded as $k \rightarrow \infty$. This is a contradiction. Therefore, $S$ must be bounded.

To verify that $S$ is closed, let $(x_n)_{n\in\mathbb{N}} \subseteq S$ satisfy $x_n \rightarrow x \in X$. We aim to show that $x$ is contained in $S$, so that [[#lem:sequential-closure][Lemma 10.3.6]] then yields that $S$ is closed. Since $S$ is compact, there is a subsequence $(x_{n_j})_{j\in\mathbb{N}}$ that converges to some $y \in S$. Since $(x_{n_j})_{j\in\mathbb{N}}$ is a subsequence of a sequence converging to $x$, it must also converge to $x$. By uniqueness of limits, $x = y \in S$.
#+end_proof

* Theorem:     Heine-Borel theorem in $\mathbb{R}$
:PROPERTIES:
:CUSTOM_ID: thm:heine-borel
:LECTURE_REF: 1.3.11
:END:

Suppose that $\mathbb{R}$ is equipped with the standard metric. A set $K \subseteq \mathbb{R}$ is compact if and only if it is closed and bounded.

#+begin_proof
- ($\Rightarrow$) Suppose that $K \subseteq \mathbb{R}$ is compact but unbounded. Thus, there is a sequence $(x_n)_{n\in\mathbb{N}} \subseteq K$ such that $|x_n| > n$, for $n \in \mathbb{N}$. This sequence must have a monotone subsequence in $K$ that is also unbounded. However, every subsequence of this subsequence must also be unbounded, hence, cannot converge. This violates compactness since every sequence must have a convergent subsequence. Hence, $K$ must be bounded.

  Now suppose that $K \subseteq \mathbb{R}$ is compact but not closed. Thus, the complement is not open and there must be some $x \in \mathbb{R} \setminus K$ such that $B_\epsilon(x) \not\subseteq \mathbb{R} \setminus K$ for all $\epsilon > 0$. In particular, for all $\epsilon = \frac{1}{n+1}$ for $n \in \mathbb{N}$. Therefore, there is $x_n \in B_{\frac{1}{n+1}}(x) \cap K$. This sequence $(x_n)_{n\in\mathbb{N}} \subseteq K$ converges towards $x \notin K$. Hence, none of its subsequences can converge in $K$. Hence, $K$ must be closed.

- ($\Leftarrow$) Conversely, if $K$ is closed and bounded, then every sequence in $K$ is bounded and hence admits a convergent subsequence by Bolzano-Weierstraß. Closedness ensures that the limit lies in $K$, so $K$ is compact.
#+end_proof

* Lemma:       Truncating the metric preserves convergence properties
:PROPERTIES:
:CUSTOM_ID: lem:truncated-metric-convergence
:LECTURE_REF: 1.3.12
:END:

Let $(X, d)$ be a metric space and define

$$d_1(x, y) := \min\{1, d(x, y)\}, \quad x, y \in X$$

Then the following hold:

1. $d_1$ is a metric.

2. For a sequence $(x_n)_{n\in\mathbb{N}} \subseteq X$ and $x \in X$,

   $$x_n \rightarrow x \text{ with respect to } d \iff x_n \rightarrow x \text{ with respect to } d_1$$

3. $K \subseteq X$ is compact with respect to $d$ if and only if $K$ is compact with respect to $d_1$.

#+begin_proof
(i) To verify that $d_1$ is a metric, we first observe that (M1) and (M3) are obviously satisfied. For the triangle inequality (M2), we compute

$$\min\{1, d(x, z)\} \le \min\{1, d(x, y) + d(y, z)\} \le \min\{1, d(x, y)\} + \min\{1, d(y, z)\}$$

so that $d_1$ is a metric.

(ii,iii) The convergence claim is obvious because $d_1(x_n, x) \rightarrow 0$ if and only if $d(x_n, x) \rightarrow 0$. Compactness is defined via converging subsequences. $\square$
#+end_proof
