*** Master theorem (Theorem 4.1)
:PROPERTIES:
:LECTURE_REF: lec_04
:CUSTOM_ID: lec04-a-master-theorem
:END:
Signal: "this is one of the theorems that might be for the exam"
Let $a > 0$ and $b > 1$ be constants and $f(n)$ the driving function, with
$$T(n) = a\, T(n/b) + f(n)$$
(or the floor/ceiling form $T(n) = a' T(\lfloor n/b \rfloor) + a'' T(\lceil n/b \rceil) + f(n)$, $a' + a'' = a$). The watershed function is $n^{\log_b a}$. Then [reconstructed; ASR garbled, matches CLRS 4th-ed canonical form]:
1. If $f(n) = O(n^{\log_b a - \epsilon})$ for some $\epsilon > 0$, then $T(n) = \Theta(n^{\log_b a})$. [reconstructed]
2. If $f(n) = \Theta(n^{\log_b a} \lg^k n)$ for some $k \ge 0$, then $T(n) = \Theta(n^{\log_b a} \lg^{k+1} n)$. [reconstructed]
3. If $f(n) = \Omega(n^{\log_b a + \epsilon})$ for some $\epsilon > 0$ and the regularity condition $a\, f(n/b) \le c\, f(n)$ holds for some constant $0 < c < 1$ and all large $n$, then $T(n) = \Theta(f(n))$. [reconstructed]

** B. Implicit emphasis (inferred)
*** RANDOMIZE-IN-PLACE: loop invariant, correctness proof, and running time
:PROPERTIES:
:LECTURE_REF: lec_10
:CUSTOM_ID: lec10-b-randomize-in-place
:END:
Signal: "Remember that because this is an important algorithm"

Loop invariant [reconstructed]: prior to iteration $i$, the subarray $A[1..i-1]$ contains an $(i-1)$ permutation drawn from $A$, and every such $(i-1)$ permutation appears with probability
$$\frac{(n-i+1)!}{n!}.$$

Maintenance [reconstructed]: let $E_1$ = "$A[1..i-1]$ holds a fixed $(i-1)$ permutation $\langle x_1,\ldots,x_{i-1}\rangle$"; let $E_2$ = "$x_i$ is chosen for $A[i]$ in iteration $i$." Since $E_1$ and $E_2$ are not independent:
\begin{align*}
\Pr[E_1 \cap E_2] &= \Pr[E_2 \mid E_1]\cdot\Pr[E_1] \\
                  &= \frac{1}{n-i+1}\cdot\frac{(n-i+1)!}{n!} \\
                  &= \frac{(n-i)!}{n!},
\end{align*}
which equals $\frac{(n-(i+1)+1)!}{n!}$, confirming the invariant for iteration $i+1$.

Termination: at loop end $i = n+1$, so every permutation appears with probability $\frac{0!}{n!} = \frac{1}{n!}$.

Running time: $O(n)$ (one pass; one random draw and one swap per step).

*** BUILD-MAX-HEAP runs in O(n), not O(n lg n)
:PROPERTIES:
:LECTURE_REF: lec_10
:CUSTOM_ID: lec10-b-build-heap-on
:END:
Signal: "definitely looks like it'd be n log n. And the point is, it isn't."

Tool used in proof: MAX-HEAPIFY called at a node of height $h$ costs $O(h)$, i.e., $T(v) = O(h(v))$.

Cost bound [reconstructed]:
$$T(n) \le \sum_{h=0}^{\lfloor \lg n \rfloor} \left\lceil \frac{n}{2^{h+1}} \right\rceil \cdot O(h) \le cn\sum_{h=0}^{\lfloor \lg n \rfloor} \frac{h}{2^h}.$$

Key identity (differentiate the geometric series $f(x) = \frac{1}{1-x/2}$ and evaluate at $x = 1$) [reconstructed]:
$$\sum_{h=0}^{\infty}\frac{h}{2^h} = f'(1) = \frac{1/2}{(1/2)^{2}} = 2.$$

Therefore $T(n) = O(n)$.

*** Comparison-sort worst-case lower bound $\Omega(n \lg n)$
:PROPERTIES:
:LECTURE_REF: lec_12
:CUSTOM_ID: lec12-b-comparison-sort-lower-bound
:END:
Signal: "you still should know that you cannot sort things faster than $n \lg n$"
A binary tree of height $h$ has at most $2^h$ leaves, so $2^h \ge n!$ gives $h \ge \lg(n!) = \Theta(n \lg n)$ (Stirling). Hence any comparison sort has worst-case running time $\Omega(n \lg n)$, and merge sort, heap sort, and randomized quicksort (in expectation) are asymptotically optimal among comparison sorts.
